# `embedded-cal-libcrux`: Software implementation of embedded-cal based on libcrux

This crate makes many operations from [libcrux](https://github.com/celabshq/libcrux) available in the embedded-cal ecosystem,
and uses accelerated hardware components where possible.

See [the embedded-cal documentation](https://docs.rs/embedded-cal/) for a high-level overview,
[the algorithms list](https://github.com/lake-rs/embedded-cal/blob/main/ALGORITHMS.md)
for a detailed list of which module supports which operations,
or the [crate's documentation on initialization](https://docs.rs/embedded-cal-libcrux/latest/embedded_cal_libcrux/type.Standalone.html#method.standalone).
